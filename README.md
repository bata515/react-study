
# React製三目並べ

これは、React公式チュートリアルに沿って作成された、シンプルな三目並べゲームです。
このプロジェクトは、React初学者がReactの基本を理解することを目的として作成されました。

## 機能

- 三目並べをプレイする
- 手番の履歴を確認する
- 過去の手番に戻る

## 開発環境の構築

このセクションでは、あなたのローカルマシンで開発およびテスト目的でプロジェクトをセットアップする手順を説明します。

### 前提条件

- Node.js と npm (または yarn) がインストールされていること

### インストール手順

1. このリポジトリをクローンします:
   ```sh
   git clone https://github.com/your-username/tic-tac-toe.git
   ```
2. プロジェクトディレクトリに移動します:
   ```sh
   cd tic-tac-toe
   ```
3. 必要なパッケージをインストールします:
   ```sh
   npm install
   ```

### アプリケーションの実行

開発サーバーを起動するには、次のコマンドを実行します:

```sh
npm start
```

これにより、デフォルトのブラウザで `http://localhost:3000` が開き、アプリケーションが表示されます。

## 利用可能なスクリプト

プロジェクトディレクトリでは、以下のコマンドを実行できます:

- `npm start`: 開発モードでアプリを実行します。
- `npm test`: 対話的なウォッチモードでテストランナーを起動します。
- `npm run build`: `build` フォルダに本番用のアプリをビルドします。
- `npm run eject`: プロジェクトから単一のビルド依存関係を削除します。
